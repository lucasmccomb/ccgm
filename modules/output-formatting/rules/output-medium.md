Applies to text addressed to the operator; a subagent reporting to its caller writes prose or its mandated envelope unless its spec asks for more.

# Output Medium: Lowest Rung That Carries the Content

| Content shape | Medium |
|---|---|
| Status, result, decision, short explanation | Prose |
| Flow, sequence, dependency, state machine, architecture, before/after | Diagram: ASCII in a fenced block (terminal), Mermaid (GitHub), inline SVG (page) |
| More than 5 items on more than 3 attributes; a long report to scan or revisit; data to chart | Page: the Artifact tool when present, else `ccgm-md-page` |
| A new concept the operator asked to learn | Video, only on request |

- The prose answer leads. A diagram or page adds to it, never replaces it.
- Climb a rung only when the content's shape needs it. Never choose video unprompted.
- A mandated format governs content, not medium.
- Missing tool: skip the rung and print a one-line note. Never fail the task.
- Write files and print paths. Never open a page or play a video; the operator does.
- Load the `output-medium` skill before drawing a diagram or writing a page.
