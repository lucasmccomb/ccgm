# Preset Coverage Allowlist
#
# Modules listed here are intentionally NOT a member of any preset
# (presets/*.json) and are therefore exempt from the zero-preset CI check
# in tests/test-doc-counts.sh.
#
# A module belongs here only if it is a stable module that is deliberately
# left out of every curated preset (installable via `start.sh --add <name>`
# but not bundled). Modules with "status": "beta" or "status": "deprecated"
# in their module.json are auto-excluded and do NOT need to be listed here.
#
# Format: one bare module name per line (no inline comments). Blank lines and
# lines starting with # are ignored.
#
# When a module here is later added to a preset, remove it from this list —
# the CI guard flags stale allowlist entries (a module that is allowlisted AND
# already in a preset).
#
# Currently empty: every stable module is a member of the `full` preset
# (full = all stable modules), so no stable module sits in zero presets.
